        TrajecTiers

        Drop one log of Claude Code, Codex CLI or Qwen Code (or an ATIF file). TrajecTiers converts it, groups its actions into phases and subphases with the rules below, and shows it the way the corpus pages do.

        Rules. The mandatory rules (G1–G7 and F1, the codebook's grouping rules) always apply and cannot be switched off or removed. Four optional rules (O1–O4) can be added and removed again. Custom rules set the phase or category of the actions whose command, target or tool contains some text, or the role of files whose path does. No rule can break a mandatory one: such a match is listed as skipped. Every change re-runs the analysis.

        Open an action and use + Rule from this action to start a rule from it. Export your rules as rules.json and apply them to the whole corpus with python3 -m atif.cli view --all --rules rules.json.
